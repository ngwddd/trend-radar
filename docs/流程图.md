## 三、八处已知限制（都已写进代码注释，不是口头承诺）

| # | 限制 |
|---|---|
| 1 | **同行评审 ≠ 事实正确**。权重编码"编辑流程多严"，不是"结论对不对"。被撤稿的 Science 论文曾拿到全测试集最高的 0.912 |
| 2 | 撤稿拦截**只在撤稿记录存在时生效**。从未被撤稿、只是没人复现的（LK-99、OPERA）**没有任何警告** |
| 3 | **热度加成实际不会触发**。`in_trend` 要求同一事件同时出现在社会池和热度样本，但两者分开调用 |
| 4 | `DOMAIN_TOKENS` 是**关键词表不是分类模型**，措辞不同可能判错类型 |
| 5 | 阶段权重里 `gain`/`error_prevented` 是**人工判定** —— 只能用排序，不能用绝对值 |
| 6 | **付费墙正文读不到**（Science/Cell 实测被挡），只能凭摘要 |
| 7 | `RE_QUANTITY` 单位不一致（`5278批次` 匹配不到）；`RE_PLACE` 偶有误判 |
| 8 | `test_retraction.py` **完全不覆盖社会分支** —— 5 个高优先级缺陷全在它盲区里 |

## 四、本机环境坑（脚本已内置修复，别拆）

```
Python CA 库旧    → technologyreview/HN 报"证书过期"但证书没过期 → 强制用 certifi
HN 反爬           → 浏览器 UA 返回 419                          → 该源单独用 curl UA
arXiv 限流        → 连发请求 429                                → 3 秒间隔+退避
Reddit 限流       → 同 URL 抓两次 429                           → 进程内 URL 缓存
热度榜无日期      → 套时间窗会被清空                            → class=trend 豁免
Crossref 日期     → 用 published 大刊一条都返回不了             → 改用 published-online
Crossref 勘误     → 服务端 type: 过滤不管用                     → 客户端按标题正则
Crossref select   → subtype / reference-count 不是合法字段      → 用 is-referenced-by-count
BOM               → PowerShell 写 BOM，json.loads 报错          → 读文件用 utf-8-sig
控制台 GBK        → 中文乱码                                    → reconfigure + 结果写文件
```

**最阴的一条**：`nature.com/*.rss` 返回 **HTTP 200** 但是 3 KB 的 bot 挡页。**状态码骗人。**
